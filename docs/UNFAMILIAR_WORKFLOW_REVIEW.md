# Unfamiliar saved workflow review

Local Linux candidate 0.3.38-native-preview.7, based on the installed .6.
No live service or account changes; Mac builds remain held.

## Behavior

- Audited local nodes, including the eight core H3 classes, run as before.
- A saved workflow containing unrecognized nodes can open a native local-trust
  review under Local only. Previously this mode rejected it before that review.
- The review names the unfamiliar node classes and explains that unknown is not
  proof of paid execution. Only the human's checked **Trust as local and run**
  decision can create a remembered choice. Cancel/generic approval queue nothing.
- Local only remains selected. No cloud key is read or forwarded for a trusted
  local submission. Custom code may still use its own network/credentials; this
  is a human choice, not an offline certificate or a network sandbox.
- Known API/provider/pricing evidence still blocks under Local only. Under Ask
  before cloud it still needs each submission's approval, with no remembered
  local exception. Mixed graphs follow the paid evidence.
- Trust retains the existing exact saved revision, graph, connection and live
  node identity binding. Ordinary prompt/seed/reference overrides still work;
  changed models/configuration may need a revised saved workflow and new review.
- Unsaved/mismatched workflows receive the reason and the next step instead of
  only a generic spending denial. No file is saved or changed automatically.
- Velo guidance now explains how managed apply opens the review. Preview does
  not queue, open confirmation, grant trust, or retry completed work.

The existing phone decision schema is unchanged. A phone must send the explicit
eligible local-trust choice; old clients' generic Approve cannot unlock Local
only. No web client, iPhone build, relay or Apple submission is changed here.

## Verification

See parent verification notes and package-verification.json. Coverage includes
both native policies, cancellation, malformed decisions, changed source/context,
API/pricing overrides, revocation, no key forwarding, no duplicate submission,
real sandboxed preload/IPC, packaged native code and isolated editor reopening.
All new behavior uses synthetic state, with no real generation or paid inference.

This does not assert that all unknown/custom nodes are free, that every workflow
is GPU-compatible, or that every Velo task costs less than one cent. Existing
cached-usage settlement and native generation waiting remain unchanged.
